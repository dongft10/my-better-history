# Privacy Policy for MyBetterHistory

**Last updated: April 22, 2026**

## Overview

MyBetterHistory is a Chrome extension that provides an enhanced browsing history management experience. This privacy policy explains how the extension handles user data.

## Data Collection

**We do not collect, store, transmit, or sell any personal data.**

The extension operates entirely locally within your browser. No data is sent to external servers.

## Permissions

The extension requests the following permissions:

| Permission                     | Purpose                                                                  |
| ------------------------------ | ------------------------------------------------------------------------ |
| `history`                      | Read and manage your browsing history to display and delete records      |
| `tabs`                         | Detect existing history tabs to avoid duplicates; open links in new tabs |
| `favicon`                      | Display website icons in the history list                                |
| `<all_urls>` (host permission) | Fetch website favicons from favicon services                             |

## How Your Data is Used

- **Browsing history**: Used only to display your history within the extension. You can delete records, which removes them from Chrome's history.
- **No external transmission**: All operations happen locally in your browser.

## Third-Party Services

The extension uses the following third-party services to fetch website favicons:

- Google S2 Favicons
- favicone.com
- icon.horse
- favicon.yandex.net
- api.faviconkit.com

These services receive only domain names to fetch icons, not your browsing history or personal information.

## Data Retention

The extension does not store any data. All history data remains in Chrome's local storage and can be deleted by you at any time using the extension's delete functions.

## Your Rights

- You can delete individual history records
- You can delete all history records
- You can uninstall the extension at any time to remove all extension data
