## Description

```
My Better History is a modern browsing history manager. It replaces the built-in history page with a clean, searchable interface so you can find what you need fast.

Features:
- Calendar view: pick any date to see exactly what you visited that day
- Precise daily records: every visit is attributed to the day it happened
- Quick search: search across all your history with instant results
- Time filters: today, yesterday, this week, this month, and all
- Batch delete: select and remove unwanted records in one click
- Dark/light theme with one click
- Keyboard shortcuts for fast navigation
- Multi-language support (English, Chinese, French)

All data stays in your browser. The extension does not collect, transmit or sell any personal information. See the privacy policy for details.
```
